# NexusCX Agents

This file contains agent-specific instructions for the NexusCX project.
When working on this project, AI agents should follow the guidelines in this file along with the general CLAUDE.md instructions.

## Project-Specific Guidelines

1. **Follow the phased approach**: Complete each phase in order before moving to the next
2. **Test-first development**: Write tests before implementing features
3. **Use existing patterns**: Follow the coding patterns already established in the codebase
4. **Maintain clean commits**: Make focused, atomic commits with clear messages
5. **Run tests frequently**: Ensure your changes don't break existing functionality

## Current Phase

Check the memoryNEXUS.md file to see which phase is currently active and what tasks remain.

## Agent Roles

Different agents may be specialized for different tasks:
- Backend agents: Focus on FastAPI, LangGraph, WEKA, database work
- Frontend agents: Focus on Next.js, React, TypeScript, UI components
- DevOps agents: Focus on Docker, deployment, infrastructure
- Testing agents: Focus on writing and running tests
