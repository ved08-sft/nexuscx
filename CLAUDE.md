# NexusCX Project Guidelines

This file contains general guidelines for working on the NexusCX project.

## Core Principles

1. **Follow the specification**: Adhere to the requirements in PRD, SRS, and ICD
2. **Test-driven development**: Write tests before implementing features
3. **Keep it simple**: Avoid premature optimization and over-engineering
4. **Maintain security**: Never hardcode secrets, always validate inputs
5. **Ensure reliability**: Handle errors gracefully, implement timeouts and retries
6. **Follow coding standards**: Adhere to the project's linting and formatting rules

## Development Workflow

1. Check the current phase in memoryNEXUS.md
2. Complete any remaining tasks in the current phase
3. Run tests to verify your work
4. Move to the next phase only when the current phase is complete
5. Update memoryNEXUS.md with your progress

## Communication

When working with other agents or humans:
- Be clear and specific in your requests
- Provide context for your questions
- Share your progress regularly
- Ask for clarification when needed
